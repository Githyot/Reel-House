# Kana sounds

Recordings of Japanese syllables from [Lingua Libre](https://lingualibre.org) on Wikimedia Commons, trimmed
and converted to mono Ogg Vorbis by `fetch_kana.py`. Each file keeps the licence of its recording (below);
the licence of each file was read from its Commons description page. を, ぢ and づ use the sounds of お, じ
and ず. A syllable without a free recording has no file (the app stays silent for it).
